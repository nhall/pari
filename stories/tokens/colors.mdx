# Colors

Pari's color palette is inspired by the bird of paradise plant. All values use oklch. The palette splits into **decorative** colors (logos, gradients, backgrounds) and **accessible** variants (text, links, interactive elements on white).

## Usage guidelines

- **Decorative colors** (Vibrant Orange, Warm Coral) are for the logo, gradients, illustrations, and backgrounds paired with dark text. Never use them for text on white.
- **Accessible variants** are for any text, link, or interactive element that must be readable against a white or cream background.
- **Button backgrounds** come in two flavors: accessible variant fills with white text, or brand palette fills with Deep Indigo text. Both pass AA contrast.
- Every color in this system was tested against both WCAG 2.x contrast ratios and the APCA readability algorithm.
